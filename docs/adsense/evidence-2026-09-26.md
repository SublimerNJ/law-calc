## 4. Google 기준

- 게시자 콘텐츠가 없거나 가치가 적은 화면, 사람의 선별 없는 자동 생성 콘텐츠, 여러 페이지에 걸친 긴 반복 문구 → 광고 불가. 유사 페이지는 확장하거나 통합. [공식] publisherpolicies 11112688, AdSense 10015918
- 거절 화면 문구: "충분한 고유 가치, 웹에서 꾸준히 운영, 상업적 광고 파트너십을 지원하는 수준의 사용자 관심" [확인] AdSense 화면
- 대표 거절 사유로 "not enough organic traffic", "다른 곳에서 쉽게 찾을 수 있는 정보" [공식에 준함] AdSense Community Manager 공지 thread 176631357
- YMYL(법률·세무)에서 운영 책임자 정보 부족 → Low, 전무 → Lowest [공식] 검색 품질 평가 가이드라인
- 실무자 사례 11건 중 7건이 트래픽 부족, 4건이 사이트 연령. 반례(대량 트래픽인데 거절)도 4건 [사례]
